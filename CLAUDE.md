# Working in pdt-nsduh

National Survey on Drug Use and Health (NSDUH) metadata built to the PublicDataToolkit standard (`../PublicDataToolkit/STANDARD.md`). To build or improve this repo, follow `../PublicDataToolkit/instructions/`. To search the metadata, read `agent/index.md` first.

- `metadata/releases/`, `metadata/groups.jsonl`, `metadata/links.jsonl` and `build/report.md` are generated by `build/build_records.py`. Don't edit them; change the build or `build/slice.yaml`.
- `agent/`, `docs/` and `export/` are generated by `make views`. Don't edit them.
- `dataset.yaml`, `sources.yaml`, `EXTENSIONS.md`, `build/slice.yaml` and `metadata/corrections.jsonl` are edited by hand.
- `data/` is gitignored and never committed.
- Run every build under the memory cap: `systemd-run --user --scope -p MemoryMax=6G -p MemorySwapMax=0 --quiet make build`. Before it, unzip each release's `.dta` and run `pdftotext -layout` on each codebook into `data/interim/` (the names are in `build/slice.yaml`).
- Names are spelled as each data file spells them: the 2024 file writes most names in lowercase.
- Run `make build`, `make views`, then `make check`. Read `build/report.md` after every build.
- Terms questions go to a person; don't decide them.
